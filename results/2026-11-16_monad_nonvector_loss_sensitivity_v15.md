# v0.15｜オニシバリから一般化する際の花粉消失段階：非送粉性除去の感度検証

日付：2026-11-16 JST。状態：**公開原著データの再解析と仮定に基づく感度試験**。オニシバリの現地測定、繁殖成功、花乾物重、適合花粉、父性適応度の新実測ではない。

## 科学的問い

「葯から花粉が除去された」ことは「送粉者が花粉を運び出した」ことと同義ではない。Johnson & Harder (2023) 自身が、粒状花粉では風雨・震動による除去が観察されるため PTE の分母が過大になり得ることを明記している。

したがって旧 v0.14 が示した **除去後に柱頭へ届かない**という物理的分類を、そのまま **昆虫に載った後の運搬失敗**という機構に読み替えてはいけない。

## 検証方法と元データ

- Johnson & Harder (2023), *Proceedings B* DOI https://doi.org/10.1098/rspb.2023.1148。
- Original author supplementary 228-species species-median source file DOI https://doi.org/10.6084/m9.figshare.24146916.v1, original Figshare file 42364722, SHA256 e5d981d0a7b3804a7d2309b2df6e1418b86a2d9e52d850175fe69ab5a4144a9c。
- 228種のうち RE と PTE の両方の記録がある198種／20科。monads 34種／18科。ラン科111種＋キョウチクトウ科53種が元198種の82.8%を占める。
- 定義：RE=葯から消えた花粉/生産花粉、PTE=同種柱頭に記録された花粉/除去花粉、RPE=RE×PTE。
- 未観測の「昆虫以外で葯から消失し柱頭に達しない」量 q を**仮定だけで**差し引く。f=元の記録上の除去量に占めるその割合とし、q=min(f×RE, RE−RPE)。
- 昆虫の体に載る前の損失=1−RE+q、載った後に同種柱頭に届かない損失=RE−RPE−q、同種柱頭に達した量=RPE。毎種で厳密に合計100%。**物理的な葯除去後の消失量は仮定qにかかわらず不変**で、再分類されるのは機構帰属のみ。

50%シナリオで分類が必ず逆転するのは、RE≤1の範囲で q=0.5×RE を代入した数理的帰結であり、新しい生物学的閾値ではない。

**monads の未除去＋仮定した非送粉者消失／送粉者に載った後の未到達／柱頭到達：**
- f=0%：19.95%／78.52%／1.53%。
- f=10%：27.96%／70.51%／1.53%。
- f=30%：43.97%／54.50%／1.53%。

元の monad 34種のうち運搬後消失優勢の32種について、分類が反転する非送粉者除去割合の閾値は**元の記録上の除去花粉量を分母**にしたとき中央値40.67%、四分位範囲34.86–45.16%。閾値は各種のRE/PTEから代数的に算出され、実際の風雨除去率を推定した値ではない。18科を均等重みで扱うと monads の運搬後消失優勢の割合は f=0%で93.1%、f=10%で85.0%、f=30%で80.6%（科再標本化区間はそれぞれ約80.6–100%、68.3–98.9%、63.7–95.8%）。科均等重みを採用しても全球被子植物集団の母数にはならない。

## 何が前進し、何は結論できないか

**前進：** 約18科を含む monad の原資料部分では、葯から消失した花粉のうち一定割合を非送粉者に再配分しても、「葯除去から同種柱頭に至るまでの効率の低さ」の位置づけが少なくとも大部分の種で維持される。ただしこれは*送粉者の体に載った後*に限定された直接測定ではなく、強い仮定をおいた感度解析による機構ラベルの保持である。

**未同定：** どれだけが実際に昆虫に載り、どれだけが他個体に届き、どれだけが適合受精・種子・父性遺伝に変換されたか。とりわけ自家由来花粉も同種柱頭に数えられ得る。真の花建設費や訪花の個体IDもこの資料にはない。

## オニシバリへの接続

浜谷（1955）は東アジア *Daphne* 近縁群で雄的花が大きいという歴史的形態記述を残した（萼筒8–10 mm対4–6 mmは**節内の概括**であり、オニシバリの標本母平均ではない）。雄的な花の雌しべが稔性を持つかは示していない。オニシバリが完全雌雄異株か、機能的に雌性両全性異株かも、生殖実験による株ごとの判定が必要。*Besleria*の株内の雄性花→雌性利益の既知機構を、オニシバリでそのまま仮定できない。

次の識別課題：
1. 同じ独立genetの雄的・雌的形態の真の機能を、手による他家受粉・自家受粉・袋掛け・陽性対照で検証する。
2. 葯からなくなった花粉量と、実際に昆虫に載った花粉量を別々に測る（送粉者を直接観察・洗浄／トラップ・コントロール）。**単に葯内が減ったという記録では運搬機構を判定しない。**
3. 同種柱頭受領と、適合花粉管・発育胚・成熟種子・父性割当を段階的に区別する。花数と花の実乾物重は株サイズと独立に記録。
4. 訪花ゼロの機会（花が開いていた時間×努力）と新規に来訪した送粉個体数を切り分ける。翌年の株生存・花芽量も測る。
5. 野生希少株の処理上限：確認した蕾の50%以下、かつ1genet当たり確認蕾10個以下（合算）を維持する。標本で難しければ共通園や豊富な近縁対照を先行させる。

**評価：** 現状で「花が大量に作られても運搬失敗で大きく失われる」という汎植物的な機構仮説は立てられるが、繁殖成功が投資に比例しなくなる真の段階と、その進化的最適解については種内の同一genetレベルの計測がないと判定できない。論文の新規性は仮定感度の再計算それ自体ではなく、同一個体で広告・輸送・適合・資源発育・父性を分ける実証にある。
