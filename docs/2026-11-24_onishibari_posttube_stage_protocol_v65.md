# v0.65｜焦点オニシバリの「雌しべが残るが結実しない」段階を突き止める実験計画

**未実施の計画。** 対象 *Daphne pseudomezereum*。ナニワズ *D. jezoensis* の2016年人工他殖後の花粉管研究（Shibata 2020, DOI https://doi.org/10.14943/doctoral.k14152）は既報で、オニシバリの実測ではない。

## 主要推定対象

独立genet×事前登録花を基本単位にして、(A)外来・自家花粉の受領、(B)胚珠への花粉管到達、(C)受精卵／初期胚成立、(D)発達中の胚の生存、(E)果実成熟、(F)発芽と実生存続、(G)遺伝的母性・父性成功を**別々の分母**で記録する。「結実ゼロ」は生理的完全不稔とは限らず、観測時期・花粉ドナー・霜・開花同期・資源条件の変動を含む。

## 誘導する主な反証

| 遺伝的に独立な雄的H株での所見 | 次に支持される候補 | 言えないこと |
|---|---|---|
| 既知他殖でも花粉管が胚珠へ届きにくい | 柱頭／通導組織での受容障壁 | 既報ナニワズにも普遍 |
| 到達はするが初期胚が少ない | 受精成立・初期胚の生殖障壁 | 到達＝受精成立 |
| 初期胚は成立するが落果が多い | 胚維持・成熟資源または発達制御 | 葯や花径の資源配分が原因 |
| 胚・種子は成熟するが発芽しない | 種子生存・近交弱勢 | 成熟果実＝次世代寄与 |
| 同じgenetの結実有無が年次で変わる | 環境機会／状態依存という候補 | 遺伝的生理能力の不存在 |

## 実施上のガードレール

- 受粉前に独立genet、花性型、花数、開花時期を登録し、自然・袋掛け・sham・自家・**別々の複数他殖ドナー**からの花粉補充を無作為化する。ドナー差を母株H/F差と混同しない。
- 花粉管染色と胚組織観察は**破壊的**。成熟まで追う花とは別に割り付ける。同じ花を通して観測したと偽って`P(成熟|花粉管到達)`を直接推定しない。
- 時間窓ごとに胚発達と落果を同時に測り、未追跡花を「不稔=0」と一律補完しない。
- 微気象（早春の凍結・芽温）、開花日、近隣の交配相手、日中と夜間の訪花機会、個体サイズ・資源、母性成功・父性成功・花器官乾物量を別の観測項目とする。
- 野生オニシバリの操作は独立genetの確認蕾の**50%以下かつ最大10蕾**を累積上限にし、全処理×全時点を1株に掛けない不完備ブロックで組む。保全許可・栽培下での先行検証を優先する。

**研究仮説**：形態的に雌しべが残ることは、生殖成功の全段階を維持することと同義ではない。ナニワズでは花粉管到達が既報で広く成立するため、その後の受精／胚生存／成熟への変換が特に重要。オニシバリでは、まずその段階分離が同様に成立するかから実証する。
