# 1989–2023：自家花粉干渉仮説の再検証

**2026-11-14 / 文献監査。オニシバリ *D. pseudomezereum* の新規観測結果ではない。**

## オニシバリで確かめたいこと
雄的両性花の雌しべは目立った形態的退化がなくても、なぜ種子生産にあまり寄与しないのか。原因は(1)花粉不足、(2)自家花粉が柱頭を塞ぐ sexual interference、(3)内在的な雌機能低下、(4)自家不和合性、(5)近交弱勢のどれか、あるいは複合か。

## 原著の証拠を年代順に整理
1. **Kikuzawa 1989 / *D. kamtchatica* var. *jezoensis*（ナニワズ）**：公表要旨によると、両性花の柱頭には平均200粒以上、雌花には約3粒の花粉が付着。両性花の除雄のみでも、除雄と人工授粉でも結実が増加。自家花粉による柱頭閉塞 (pollen clogging) を雌性両全性異株化の原因として提案した。ただし「袋掛けで結実ゼロだから自家不和合性」という当時の推論は不十分。**ここに示す値は原著の要旨に基づくものであり、表と方法の原本照合は未完了**。DOI: https://doi.org/10.2307/3565336
2. **Alonso & Herrera 2001 / *D. laureola***：除雄の有無×自家・他家人工授粉の要因実験を実施。袋掛けだけでゼロ結実でも自家不和合性の証明ではない、とKikuzawaの解釈を明確に批判。同種は自家和合性で、自家花粉が他家花粉の受粉を妨害する可能性を示した。https://www.plant-animal.es/pdfs/Alonso%26Herrera2001AmJBot.pdf
3. **Shibata & Kudo 2017 / *D. jezoensis***：他家人工授粉の結実率は雌株60.4%、両性株21.1%、両性株の自家人工授粉7.1%。**少数でも自家授粉で結実するので完全な自家不和合性とはいえない**。同時に、他殖でも雌機能が低いので自家花粉干渉だけでは説明しきれない可能性がある。https://doi.org/10.1093/aobpla/plw089
4. **Shibata et al. 2018 / *D. jezoensis***：他殖人工授粉でも59–91%の両性株で結実せず、自殖由来の種子は発芽率が低い。自家花粉の干渉、雌機能内在的低下、近交弱勢を区別する必要。https://doi.org/10.1007/s10265-017-0978-5
5. **Shibata et al. 2021 / *D. jezoensis***：国内14集団の大半の両性株は自家和合性を維持しながら雌機能が低い。完全雌雄異株への一本道とは断定できない。https://doi.org/10.1007/s00606-021-01780-1

## もっとも判別力の高い実験
**同一両性株内で花齢を揃え、除雄あり/なしと人工他家花粉あり/なしをランダム化する**。全処理に同じ袋掛けと偽操作対照。主に「除雄＋標準量他家花粉」と「偽操作＋同量他家花粉」の結実率を比べる。さらに自家→他家、他家→自家の時間順序を操作し、柱頭の自家花粉数・他家花粉管の到達・胚発達・成熟種子・発芽を追う。雌株の他殖処理を陽性対照にする。

| 予測 | 支持される機構（確定ではない） |
|---|---|
| 除雄＋他殖 > 偽操作＋他殖 | 自家花粉干渉（ただし除雄操作の非特異的効果に注意） |
| 除雄しても両性株の他殖結実が雌株を大きく下回る | 両性株に固有の雌機能低下 |
| 自家花粉だけ花柱で伸長停止 | 生理的な自家不和合性候補 |
| 自家・他家とも受精するが自殖胚だけ失敗 | 近交弱勢または後期自家不和合性 |
| 雌株で自然結実 < 人工他殖 | 花粉不足 |
| 花が大きいほど、株サイズ・花数調整後も父性成功が高い | 雄機能への選択候補 |

## 種内・種間の比較上の注意
- *D. jezoensis* は両性花が雌花より大きい（2017）。*D. laureola* はイベリアの38集団の分析で雌株の**植物体**が大きい（2007）。花サイズ・植物体サイズ・花数は別形質。 https://doi.org/10.1093/aob/mcm254
- *D. miyabeana* の自然結実は開放林冠31.22%、閉鎖林冠9.01%（2018）。観測的比較で因果効果ではない。https://doi.org/10.1111/1442-1984.12212
- *D. mezereum* では雌型・両性型の果実率が近い集団もある（2023）。https://doi.org/10.1111/njb.03871
- オニシバリの雌性両全性異株・雌花の小型化は形態図鑑で記載されるが、ここに列挙した数値は**いずれもオニシバリそのものの実測ではない**。 https://www.jplants.jp/onsibari.html

## 次の研究上の意思決定
性型→両性株の除雄効果→自家/他家の受精障壁→発芽・父性成功→送粉者（昼夜）と環境による変動、の順で進む。花粉管・胚・父性が測れない段階では「自家不和合性が進化した」「雌しべが無駄」と断定しない。


## なぜ雌しべが残るか：重要な反証と進化の非一方向性
- **Shibata & Kudo 2022（*D. jezoensis*）**：光・土壌栄養を操作しても、両性株の低い種子生産能力はほぼ変わらなかった。果実生産が翌年の繁殖を減らすというコストも明確には出ず、雌機能の完全喪失に向かう選択圧が弱い可能性がある。ただし「雌しべの形成コストがゼロ」と直接測定した結果ではない。https://doi.org/10.1111/plb.13458
- **Alonso & Herrera 2011（*D. laureola*）**：13集団の分子系統と繁殖型の対応から、雌性両全性異株から両性のみの集団への変化を含む複数回の性システム転換を推定。**雌性両全性異株→雌雄異株の一方向進化と決めつけられない**。https://doi.org/10.1111/j.1558-5646.2011.01246.x

上記は「雌しべを退化させる突然変異が存在しても、それが増えるほど適応度が高いとは限らない」という維持仮説と整合する。しかし、オニシバリで発生的制約・残存雌機能のコスト・稀な定着時の繁殖保証を比べるには、別途の個体群追跡が必要。
