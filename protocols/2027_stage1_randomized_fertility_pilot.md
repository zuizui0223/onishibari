# オニシバリ：2027年初春の最小ランダム化実験（実行可能なv1設計）

**2026-11-14。データなし・現地操作なし。実験予定のみ。** `Daphne pseudomezereum` の雌しべが種子親として機能するか、**自家和合性と自律自殖を分けて**判定する。近縁ナニワズの種子形成の報告をそのまま適用しない。

## 新たに踏まえる原著
- `Daphne laureola` の核心・周縁集団で、柱頭への花粉付着が多くても**花粉管になる割合が低い**場合があった。花粉量・花粉管・受精成功を一つの指標へ畳み込まない。Alonso et al. (2016), *American Journal of Botany*. [PubMed 26928007](https://pubmed.ncbi.nlm.nih.gov/26928007/)。
- 自殖できるナニワズ `D. jezoensis` でも、自然自殖に訪花昆虫が必要で既存集団の繁殖保証が弱かった。Shibata et al. (2018), [DOI 10.1007/s10265-017-0978-5](https://doi.org/10.1007/s10265-017-0978-5)。
- アケビの遅延型自家不和合性研究（日本生態学会2005年大会要旨）では、**自家花粉の花粉管が胚珠に達しても果実生産が低くなる**事例が報告された。これはジンチョウゲ属の結果ではなく、花粉管到達だけで「受精後の近交弱勢」と確定できない注意例。[要旨](https://www.jstage.jst.go.jp/article/esj/ESJ52/0/ESJ52_0_673/_article/-char/ja/)。

## 実施前の第0関門：確かな形態と独立した株
1. 公開写真だけでは性型を確定できないので、萼筒、下段雄しべと柱頭、葯の発達、花粉の有無を実体顕微鏡＋voucher写真で検証する。特に**雌しべが見える＝種子親として働く**としない。
2. `population_id/genet_id/branch_id/flower_id` を発行し、同じ株の花を独立反復にしない。クローン・ラメットが多い場合は後に遺伝型でgenetを補正する。
3. 花粉飛散前の蕾だけをランダム化対象とする。開花済み／同定保留／個体ID不確かな株は除外記録として保持。
4. 交配親の識別と採集・操作許可を確認。希少種・保護地の精密な地点と個体IDを**公開repoに書かず**、ローカル非公開で管理する。

## 第一波（成熟種子まで追跡）：5アーム/性型

| 雄的両性型 H のアーム | 目的 |
|---|---|
| open | 自然条件の果実・種子形成 |
| bag_no_hand | **自律自殖**またはアポミクシス・バッグ汚染を探索 |
| bag_sham | 袋掛け＋操作のみ（花粉を追加しない）の操作影響 |
| bag_hand_self | 人工**自家**花粉授粉後に成熟種子ができるか |
| bag_hand_cross | 人工**他家**花粉を飽和に向けた事前確認量で授粉。Hの雌機能の可能性 |

| 雌型 F のアーム | 目的 |
|---|---|
| open | 自然結実 |
| bag_no_hand | 陰性対照・バッグ汚染や無融合生殖候補 |
| bag_sham | 操作対照 |
| bag_hand_cross | 同じ供与者品質・同じ授粉方法でFの雌機能を測る**陽性対照** |
| open_plus_cross | 雌型の自然花粉制限の評価 |

**袋だけをかける**処理と**袋＋花粉操作**を混同しない。各株の同一条件の花を無作為化し、枝・花齢・開花日・供与者ロットを記録。父性を確認できない自殖果実では、バッグ漏れや他殖汚染を否定しない。

## 再現可能な割付け

- 各個体の蕾を**1行1蕾**として [空の入力表](../data/templates/2027_bud_inventory_header.csv) に記録。`sex_morph` は `male_biased_morph` / `female_morph` / `undetermined`、`voucher_checked` は `yes/no`、`flower_stage` は `predehiscence/open/not_ready`。
- `analysis/randomize_2027_pilot.py` が同定確認済みかつ飛散前の蕾を**同一株の中で5アームへ均衡割付け**する。最低5蕾／株に満たない株を無理に割り付けず、スキップ理由を保持。結果は**予定表であり授粉が成功した記録ではない**。
- 再現のためのシード値は `20271114` を例示。現地のプレ登録時に固定し、割付け前の個体リストは凍結。スクリプトを使う際の例：
```bash
python3 analysis/randomize_2027_pilot.py --self-test
python3 analysis/randomize_2027_pilot.py \
  --inventory data/private/2027_bud_inventory.csv \
  --output data/private/2027_randomized_assignments.csv --seed 20271114
```
- `data/private` は公開対象外とする運用が必要（.gitignoreへ追加予定）。割付けの出力には交配親IDは空欄のまま。**現地で受粉操作したら必ず別の実施ログと供与親識別を記入**し、推定データとして自動で使わない。
- 2027年の実際の蕾数・雌雄比・株間ばらつきが未知なので、5アームの均等割付けに必要な総株数を現時点で「十分」と断言しない。

## 第二波：花粉管・胚形成の破壊採取

第一波の果実結実率だけで判断しない。追加の**別花**に同じ袋掛け自殖/他殖操作を割り付け、柱頭受粉粒数・花粉管（時間差固定）・胚珠到達・胚形成・早期胚の消失までを追跡する。第一波の果実用花を破壊しない。同量の自家・他家混合花粉での干渉試験は[別の詳細v2](2027_pollen_identifiability_v2.md)に置き、第一波の分子生態機構が分かってから実施する。

## 可能な観測パターンと論理

| 実験結果 | 適切な結論 | まだ言えないこと |
|---|---|---|
| Hの人工他殖で生存種子を得る | Hの雌機能は完全には失われていない | 雌しべ残存が適応的選択で維持された |
| Hの人工自殖で種子を得るが、袋だけでは0 | Hは人工授粉条件下で自殖可能だが、**自律自殖は未確認** | 送粉者不在で繁殖保証が働く |
| Hの袋のみでも種子を得る | 自律的な種子形成と整合 | 真正の自殖か、無融合生殖・外来花粉汚染か |
| Hの自殖人工授粉で果実0、他殖で果実あり | 自殖側の繁殖障害が存在 | その原因が受精前SI、遅延型SI、近交弱勢のどれか |
| Hの他殖0、Fの他殖成功 | Hの内在的雌機能制限に整合 | Hが100%不稔、雌しべが発生遺物であること |
| HもFも他殖0 | 実験手技・花粉活性・環境などの対照不成立候補 | 両性株固有の雌機能欠如 |
| Hの人工自殖は結実し、子が低生存 | 自殖に伴う初期適応度低下と整合 | 近交弱勢の程度（母系と父性を確認しなければ不可） |

## 統計上の重要な禁止事項
- 40花の全てが同一個体なら、40独立株とは違う。「40花中0結実」だけで雌機能完全喪失を主張しない。
- 特に「自家花粉管が胚珠に到達した」だけで受精成立は確定しない。遅延型SIの可能性が残る。
- 初年の結果は母株単位の効果量と区間推定、胚段階ごとの効果を主報告。低結実で全0の場合は**独立株ごとの成功/失敗**の上限も併記し、花はクラスター内部単位として扱う。
- 他種 `D. jezoensis` の低結実率をオニシバリの仮説検定の真値として扱わない。

以上のワークフローは**採集許可・研究倫理・現地株の確認後に初めて実施可能**であり、今回のスクリプトで生成したのは割付け規則のみ。
