# オニシバリ 2027年：雌しべ残存仮説を「測れる研究」にする最小フィールド計画

更新: 2026-11-14。**実験未実施・サンプルサイズは仮置き**。対象：*Daphne pseudomezereum*。以前の[総合計画](2027_field_protocol.md)、[自家花粉干渉v2](2027_pollen_identifiability_v2.md)、[理論閾値](../docs/2026-11-14_retained_pistil_thresholds.md)を接続。

## 研究で区別すべき4つのパラメータ

- **S（配偶者不足時に追加される自殖由来の成熟種子数）**：自殖が生理学的に可能かだけでなく、実際に**他殖相手と送粉者が不十分な場所で形成される自殖種子**があるか。袋掛けは自律自殖の有無を直接検証するが、袋掛けにより温度・湿度が変わるためシャムと他家受粉の陽性対照が必要。
- **r（自殖子の生存／他殖子の生存）**：自殖・他殖人工授粉に由来する成熟種子の遺伝的父性を確認し、発芽から複数年間追跡。2020年のナニワズr=0.407は**オニシバリには代入できない**。
- **c（雌機能保持によって失われる雄機能の成功）**：理論の仮想的な完全雄型との比較。**オニシバリに完全な雄型が存在しなければ直接同定できない**。結実を増減させる無作為操作、花数・花サイズ・花粉生産・子の父性解析で、一部の生殖配分コストに限って実験推定できる。雌しべ形成の発生的コストそのものとは異なる。
- **p（有効な配偶者を欠く繁殖機会の割合）**：生息域の距離ではなく、同年・同所での両性花の同時開花、花粉管が到達できる確率、互換性、開花日、年ごとの変動を測る。**単年調査では生涯pを推定できない**。

## 3段階の優先順位

### Gate 1（最優先）：雄的両性花の雌機能は本当にあるか

1. 2～3か所以上の現存集団で、同定を確かめた**標識した独立株（genet）**を選び、雄的両性型・雌型を花器官で判別。可能なら集団ごとに各性型20株以上を探索目標とするが、実在数が少ないときは無理に確保せず全数把握。必要サンプル数は予備効果量と株内相関を得てから計算。
2. 株サイズ（枝数・樹冠幅・高さ）、開花数、花筒長と花裂片、葯のサイズ・花粉の稔性、柱頭、胚珠を**別々に測定**。同じ株の複数花を独立な株として扱わない。
3. 両性型の同一株内で以下の処理をランダム配置：自然開放、袋掛け無人工授粉（自律自殖・無受粉）、袋掛け人工自家授粉、袋掛け人工他家授粉。雌型で開放、無授粉袋掛け、人工他殖、開放＋追加他家花粉。
4. 各処理の花、早期胚珠、成熟果実、種子、発芽を連鎖的に記録する。雄的な花で**他家授粉でも結実しない**なら、柱頭から胚形成までの段階を別花で追跡。
5. **同一株の花で自殖種子ができたと仮定しない**。自然の袋掛けや花序操作のミス、受精以前の付着花粉を監査し、可能なら母子の遺伝子型で自殖を検証する。

### Gate 2：自殖能力が稀に有利になる環境はあるか

6. 各雌株・両性株の周辺1、3、10mの**同時開花する花粉供与者の花数**を数え、日内訪花、温度、風、開花日、柱頭への花粉数を測定。これらの距離半径は探索的で、最終的な尺度選択は事前登録する。
7. 孤立度の異なる標識両性株で開放/袋掛け自殖/人工他殖と種子父性・発芽を追う。自殖が有効な条件は「配偶者が少ない場所でも**生き残る自殖子ができる**」であり、花粉付着のない場所での結実が0ならS=0の可能性を優先する。
8. 2027年以降も毎年同じ個体を再訪し、標識した性型が変化するか、花数・結実・株の生存と資源を追跡する。集団の孤立度を当年だけでpと同一視しない。

### Gate 3：雌しべを残すことで雄機能がどれだけ犠牲になるか

9. 十分な花数のある両性株で**結実促進（他殖花粉追加）／成熟果実の早期除去／偽操作**を無作為に分け、翌年の開花数、花粉数、花粉活性と可能なら**母株の父性成功**を追跡。果実を除去するとその種子の潜在利益は失われるため、直接の種子利益と将来花粉投資は別々に記載。
10. 花期前の貯蔵炭水化物（NSC）、秋冬の葉面積、森林林冠開空度を個体・年で対応させ、資源制限がコストに与える影響を事前指定。採取許可がない場合、非破壊の葉量・照度測定だけで開始できる。
11. 全集団に「雌しべを持たない純雄」がいなければ、**雌しべを持つこと自体の適応度コスト**は実験だけで完全には識別できない。発生的拘束・祖先形質維持・選択の弱さを競合仮説として残す。

## データ構造（先に作ったテンプレートに追加）
- 測定単位は `population_id / genet_id / year / branch_id / flower_id / treatment`。
- `observed_bag_control` と `bag_self` を混同しない。自動自殖、補助自家授粉、訪花者による自殖を区別する。
- `seed_id` がある場合、母株・父親判定・発芽日・生存日を別テーブルで記録する。
- `sex_morph_morphological` と `sex_morph_functional` は独立。後者は受精・種子データなしでは `unknown` とする。
- 全地点の詳細座標は公開GitHubにコミットしない。公開集計には市町村・生息域保護上の粗い地理情報だけを使用。

## 最小の判断表

| 結果 | 対応する解釈 |
|---|---|
| 両性花の他殖でも成熟種子0 | 内在的な雌機能低下の候補。自家不和合性のみでは説明不可 |
| 両性花の他殖で種子形成、袋掛け自殖も形成 | 自殖可能性あり。ただし孤立地で機能するか、胚・種子の生存を調べる |
| 自家花粉だけ花粉管が停止 | 受精前自家不和合性候補。株・供与花粉の品質対照が必要 |
| 両性花で他殖結実はできるが、自然条件では低率 | 花粉不足・自家花粉干渉・資源不足などを追加切り分け |
| 自殖後3年間まで生存し、孤立環境での自殖種子が確認 | 稀な繁殖保証仮説が**検証可能**になる。まだ進化的維持の証明ではない |
| 翌年花数・花粉親成功が果実操作で変化 | 配分コストの操作証拠。ただし雌しべ自体の発生コストとは別 |

**最初の1シーズンではGate 1を確実に実施し、Gate 2の下準備を優先する。Gate 3の長期的な適応度結論を急がない。**
