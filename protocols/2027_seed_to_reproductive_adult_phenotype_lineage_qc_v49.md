# v0.49｜花から子へ、子から繁殖成体へ：2027年オニシバリ実験の長期ステージ監査

2026-11-17 JST。**生存データはまだ取得していない。** v0.49は2027年に予定されるオニシバリ D. pseudomezereum の花粉源別実験v0.45／実施・種子監査v0.47に、**母株の個別花ID→子のseed_id→複数年の生死・発達段階**を追加する非公開データ監査である。CIは合成データだけで検証し、ユーザーの実際の稀少生物の座標・交配実験番号・親子遺伝型を公表しない。

## なぜ必要か：種子までの成功が適応度にならないことがある

Medrano, Alonso & Herrera (2005), *Heredity* DOI https://doi.org/10.1038/sj.hdy.6800550 は *Daphne laureola* 5集団の成熟種子を遺伝的に調べ、雄的両性株Hの成熟種子の推定自殖率87.5〜99.9%を報告。一方、同地域の成体遺伝子型による近交係数は、交配率から予想される均衡値より4/5集団で低いと報告。これは**自殖子が成体まで残りにくい可能性を示す間接比較**で、同じ子を追った直接生存実験ではない。原著表を確認したv0.48再解析と説明は PR#3 の results/2026-11-17_daphne_early_fruit_vs_late_genetic_recruitment_v48.md にある。

この研究の教訓は、雄的Hの雌しべが結実した、種子が成熟した、発芽したという結果が、**将来の生殖成体を残したことと同義ではない**という点。したがって保全状況に応じ、親子由来が分かる子の長期追跡・不明化の記録が必要になる。

## 入力構造（すべて非公開 data/private へ）

1. v0.45の予定割付けCSV：花の population_id/genet_id/branch_id/flower_id、形態型、予定の手動自家／他家源。
2. v0.47の実施ログCSV：実際の袋・花粉量・花粉活性・授粉時刻・同花／別花同genet／異genet供与者のIDと検証状態。
3. v0.47の母株花別果実・発芽・親子解析の集計CSV：成熟果実数、成熟種子数、発芽種子数、予定父母由来が確認できた発芽子数、評価日。
4. **新しいv0.49の子ごとの縦断CSV**：空ヘッダー data/templates/2027_v45_seed_to_reproductive_adult_ledger_header.csv。識別される各子の seed_id、元の母株花ID、観察日、観測した段階、運命、遺伝的自家/他家判定、核マーカーによる判定QC、実際の成体の繁殖の証拠、育成環境。

各seed_idは**元の母株花の4つのIDとセットで**識別する。同じseed_id文字列を別の母花に使っても誤結合しない。1株が産んだ複数の種子は独立した母株ではない。栽培下で発芽・生存させた場合は natural_field と同じ自然加入率とみなさない。

## 段階と明確な変換ゲート

- mature_seed：成熟種子の識別ができた（遺伝型父性が未確認でも収集段階として記録可能）。
- germinated：発芽が観察された（成熟果実とは異なるアウトカム）。
- established_seedling：自然・栽培環境に応じて予め定義された定着幼植物の段階。**閾値は現地実施前に凍結**。
- juvenile：未繁殖の生存個体の段階。
- reproductive_adult：開花を直接観察し reproductive_evidence=flowering_observed とした場合、あるいは自ら子を作ったことが確認され offspring_parentage_confirmed とした場合のみ。**大きいだけで繁殖成体と認定しない**。
- 同じ子に status=lost/pending がある場合は**追跡不能／未観察であり死亡ではない**。確認死亡後の alive/lost/pending 復帰や生きた子の段階逆転はエラー。観測のない時点の死亡時刻を補間しない。

**Strict parental fitness stage** は、予定と実施した花粉源が一致し、母株の成熟果実・種子追跡が完了し、子の父母由来がマーカーで確認され、段階到達が直接追跡された場合にだけ報告。自殖と他家は同じ核遺伝子型でも誤判定し得るので、マーカー情報量とQCが不可欠。F型とH型を直接比較する場合の株数、同時期の受粉・育成環境、処理脱落を必ず分母に含める。

## 強制的な品質ゲート

- 子の種子IDが予定した母花IDに対応していない → エラー。
- 花粉供与専用花を母性子の親として登録 → エラー。
- 同じ母花で追跡した識別種子数が、v0.47の成熟種子数より多い → エラー。
- 子の発芽段階数がv0.47母花の発芽集計より多い → エラー。
- 完全に追跡できた子の実際の発芽より**前の日付**に、母花の発芽完了を記録した場合 → エラー。
- 同花・同株別花の自家受粉の子が核マーカーで他家と判明 → 当初予定通りの自家の成功として集計しない。
- H他家受粉の子が自殖由来と判明 → 当初予定通りの他家成功として集計しない。
- 親子確認数が実測発芽数を超える → v0.47でエラー。
- 確認死亡した子を再び生存・追跡不能と扱う → エラー。
- 自然林内と栽培条件の移行 → 環境変更をカウントし、自然加入率として単純合算しない。
- 母花の結果や子の追跡がない場合 → **不明／欠測**。0成功へ代入しない。

**重要な統計的限界**：このコードが出すのは観測された子ごとの段階到達数・検証済み子の数・追跡不能数であり、**打切り処理を含む不偏の生活史生存率、生涯繁殖適応度、真のH雌しべ維持への淘汰係数ではない**。長期解析には別に、配偶子/発芽の捕捉確率、育成環境、同一遺伝的親由来の子の相関、死亡・追跡不能の打切りモデル、自然での再生産を推定する必要がある。

## 実行手順

合成テスト：python3 analysis/audit_2027_seed_to_reproductive_adult_v49.py --self-test

実際の非公開入力が得られてからのみ使う方法：

    python3 analysis/audit_2027_seed_to_reproductive_adult_v49.py --schedule data/private/2027_v45_schedule.csv --execution data/private/2027_v45_execution.csv --mother-followup data/private/2027_v45_mother_fruit.csv --seed-ledger data/private/2027_v45_seed_history.csv --output-private data/private/2027_v45_life_stage_audit.json

**原データと個体ID・正確な場所をGitHubにコミットしない。** 現地における親株の保全操作上限は合算で確認蕾50%以内かつ10蕾/genet以下。播種や苗の移植には別途必要な保全・土地管理・許可条件があり、野外に自動放流するものではない。

## 再現と状態

合成テストでは 2架空genet・24蕾・H7役割/F5役割、1架空H他家子について種子成熟→発芽→定着→未繁殖若齢→開花成体→次世代の親子確認という架空の履歴を用いた。元花粉源の逸脱、自殖/他殖取り違え、子の追跡不能、確認死亡後の復活、元母花の種子数を超える幽霊子、母花集計が子の発芽日より前の誤記を試験し、失敗を正しく検出する。

**これはQC用の架空データのみで、生存したオニシバリの遺伝的子孫が1株いるという研究結果ではない。** 既存の原著の生殖成功段階の比較が、新しい焦点種の野外予測を直ちに証明するわけではない。
