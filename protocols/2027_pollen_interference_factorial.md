# オニシバリ：2027年の自家花粉干渉テスト（事前計画）

**状態：未実施。結果を保証しない。** 既存の`2027_field_protocol.md`のなかでも最優先の機構切り分け。

## 研究の順番
1. 種の同定と花型：`D. pseudomezereum` とナニワズを区別。両性型は葯・花粉・柱頭・胚珠を、雌型は不稔葯を確認。「雄株」を単に無結実株で定義しない。
2. 開花個体ID・花序IDを決め、同齢花に下記を**株内ランダム割付け**。花はサンプル、株が生物学的反復。標準化した別株由来の他家花粉を使用。
3. 柱頭花粉数→花粉管→胚珠/胚→成熟果実→発芽の各段階を別の花で調べる。袋掛けの自殖結果と自家不和合性を同一視しない。
4. 実験を成功させたのち、昼夜送粉と性型別の花サイズ・花数・父性成功を記録。

## 実験A：袋掛けした両性花の2×2

| 処理 | 除雄 | 人工他家花粉 | 目的 |
|---|---|---|---|
| I0 | なし（偽操作） | なし | 自律結実・柱頭への自家花粉の基線 |
| I1 | なし（偽操作） | あり（標準量） | 自家花粉が存在し得る場合の他殖 |
| E0 | あり | なし | 無授粉の除雄対照 |
| E1 | あり | あり（I1と同量） | **I1との差が主要な干渉検証** |

**注意：全て袋掛けする上表では野外自然送粉の効果を測れない。** 無処理の開放区、偽操作した開放区、除雄した開放区を別に設置。I1の柱頭に自家花粉が付いていなければ、干渉効果の解釈はできないため、自家花粉を規定量追加する機構実験も設ける。

## 実験B：自家/他家の順序（両性花は除雄して比較）

| 処理 | 花粉付与 | 目的 |
|---|---|---|
| S | 自家花粉のみ | 自家結実能力 |
| X | 他家花粉のみ | 内在的な雌機能 |
| SX | 自家を先、一定時間後に他家 | 先行自家花粉の干渉 |
| XS | 他家を先、同時間後に自家 | 順序依存性 |
| M | 自家/他家を同時混合 | 競争と質の効果 |
| F-X | 雌株に他家花粉 | 陽性対照（雌機能） |
| F-0 | 雌株の無受粉袋掛け | 陰性対照 |

S/X/SX/XS/Mで**総花粉量をそろえた比較**を設ける。X+X2（2つの別株他家花粉、総花粉粒数をX+Sと一致）とX+S（1つの他家＋自家）を最優先の主対比にする。Xのみ（総花粉量半量）は花粉総量の効果を推定する**補助**対照とし、自家花粉の同定にはマーカー・染色等の検証を要する（各花粉の内訳・花粉供与株IDを記録）。花粉の生存率・受粉から固定までの時間、花齢、天候を統制。受精率と果実率を混同しない。

## 初年度の観測目標（パイロット）
少なくとも複数集団、雌株・両性株とも可能な範囲で独立株を確保し、同一株の複数花を上記各処理に割付ける。集団ごとの性比と花数で設計可能性が変わるため、**未取得データから必要サンプル数や検出力を断定しない**。初年度の株内相関・結実率を見て本試験の事前必要数を計算する。

## 解析（データ取得後）
- **主対比：除雄花における `X+S − X+X2`**（同一総花粉量で自家花粉が混入したときの差）。`X+X2 − Xのみ` を花粉量の副次対比とする。`E1 − I1` は自然な花粉落下経路の**補助**検証であり、除雄操作の非特異的効果があるため単独でself-specific cloggingを証明しない。`E1 − F-X` は性型の内在的雌機能を比較する副次対比。
- `fruit (0/1) ~ emasculation * outcross + bloom_date + canopy + (1|population) + (1|plant_id)`。処理交互作用が識別可能なデザインか先に確認。
- `self pollen grains`, `cross pollen tubes per ovule`, `embryo formed`, `fruit set`, `seed germination` を別アウトカムとして区間推定。
- 父性推定に進む場合は雌株・両性株の遺伝子型と花粉供与株を記録し、近縁ナニワズ用マーカーの転用可能性は事前検証が必要。

## 重要な判定
- **`X+S < X+X2`**（等量・除雄済み）かつ自家花粉の先着が他家花粉管を阻害：自家花粉の受精前干渉を支持。ただし自殖胚の早期死亡や他家ドナー品質差との区別を必ず行う。
- `E1 > I1` かつ I1に自家花粉過剰：自然条件での雄しべ由来干渉に整合するが、**除雄の傷害・蜜・花齢変化の影響を除くまで決定的ではない**。
- `E1 ≈ I1 << F-X`：両性株の受精/胚の内在的な雌機能低下が候補。
- 自家花粉が花柱で止まり他家花粉が伸長：受精前自家不和合性候補。自家胚のみ後で失敗：近交弱勢/後期自家不和合候補。
- 開放雌株の結実が花粉添加で改善：花粉制限。
- **「自家不和合性」「近交弱勢」「自家花粉干渉」は必ず分けて報告する。**

採集・花序操作・設置許可の確認を必須とする。有毒果実は食べない、皮膚接触にも注意。


## 2026-11-14 補足：局所性比と距離勾配を因果上どう扱うか
- Chandler & DeMarche (2026) *AJB*, *Silene acaulis*: 同じ集団の総性比ではなく、**各雌株の周囲の局所的な両性株密度**が受粉・雌株の繁殖成功と対応。これはオニシバリの証拠ではなく、事前に空間デザインへ組み込む動機である。https://doi.org/10.1002/ajb2.70282
- 全開花株を位置記録し、雌株の周囲（暫定半径1m・3m・10m）の**花粉を出す両性株の開花数**を測定する。半径は事前に決め、後付けの最適半径選択を避ける。近隣雌株密度・林冠開空度・温度・開花日も測る。
- 花粉到達量（実測柱頭花粉数）と自然結実を直接比較し、花粉追加で改善するか検証。**局所両性株の不足が雌株の結実を下げる**ことは仮説であり、未検証。
