# オニシバリ 2027年早春：繁殖生態の試験計画（ドラフト）
作成: 2026-11-14 / **計画書であり、観測・解析完了を意味しない**

## 論文の中心仮説
**雄的な両性株の大きな花は雄機能への投資であり、雌しべの形態的残存は十分な他家花粉の下でも低い胚・種子産生と共存する。この繁殖様式の維持には、早春の不安定な昼夜送粉と低い雌機能喪失コストが関係している可能性がある。**

## 必須の確認（観察開始時）
- 種を同定する。ナニワズ（D. jezoensis）と混同しない。voucher写真・位置・萼筒・萼裂片・葉を記録。
- 「雄株」と呼んでいる個体の花には本当に正常な柱頭・子房・胚珠があるか。外形/断面/花粉管/果実で分ける。
- 雌型は正常な花粉をつけるか。葯の縮小や花粉不稔を実体顕微鏡で判定。
- 株の高さ・葉・枝/冠幅と花そのもののサイズを区別する。
- 性型は複数花で判定。前年に結実しなかっただけで「雄型」とは判定しない。年次の性型変化も追跡。

## 推奨デザイン（最小パイロットを超えた目標）
- 3地域 × 地域あたり3集団（可能な範囲で） × 各集団30–50開花個体。予算と集団規模によって段階的に実施。
- 個体IDは年をまたいで維持、性型は毎年再記録。正確な株距離（m）、光環境、開花日、温度を取得。
- 花数・花サイズ・葯数/花粉数・柱頭状態・蜜/香気・果実/種子成熟を各性型で測定。
- 同一株内の花を独立の株として扱わない。集団/株/枝の階層を維持。

## Experiment A: 雌機能障害と自家不和合性の弁別
**花ごとに事前ランダム割り付け、花序/枝でブロック化。処理個数は各株の花数に応じて調整。**
- A1 開放自然受粉（両性型・雌型）
- A2 事前袋掛け・無操作（自律的自家受粉、アポミクシス、バッグ汚染の検討）（両性型・雌型）
- A3 袋掛け＋手動他家授粉（両性型・雌型）：別株で遺伝的に異なる供花源、同じ量の新鮮花粉
- A4 袋掛け＋手動自家授粉（両性型のみ）
- A5 開放＋他家花粉追加（両性型・雌型）：自然の花粉制限を測る
- 可能なら A6 偽操作・除雄処理のコントロールと、雄的両性花の除雄後他家授粉による自家花粉干渉の除外
- 花粉管調査に別花を割り付け、同じ授粉処理後の定時固定（例24h, 48h, 72hを予備試験で決定）、アニリンブルー染色、胚珠到達・胚発達を調べる。
- 成果: 果実/花、成熟種子/花、生存種子/花、発芽/種子、花粉管到達/柱頭花粉粒数。
- 結実0でも「自家不和合性」と断言しない。自家・他家授粉の花粉管、胚発達、感染/物理損傷の原因を順次識別する。

## Experiment B: 昼夜の送粉者利用
- 雌型で **昼のみ開放、夜のみ開放、24時間開放、24時間袋掛け** をランダム化。
- 昼/夜は実際の日出・日入と一致する時間に開閉し、開放時間数・気温・降雨・風を必ず記録。
- 訪花の分類群・接触部位・一訪花時間・花粉運搬を撮影。訪花＝有効送粉ではない。
- 柱頭花粉数、花粉管/結実と対応。夜だけに訪花があっても結実差がなければ寄与未確定。
- 香気: 昼夜×雌型/両性型のdynamic headspace/GC-MS、空袋/葉のみのブランク、温度・開花齢を揃える。機器がなければ「匂いなし」と書かない。
- 長期でできれば花粉父性解析（microsatellite/MIG-seq/SNP）。父性によって雄適応度を測る。

## Experiment C: 雄花の大型化
- **花幅・萼筒長・萼裂片長・花乾燥質量・花数・株高さ/冠幅・枝数・光量** を同時に計測。
- 直接効果: 雄型の花サイズと訪花確率、花粉運搬、父性成功度（可能なら）との関係。
- 植物体サイズの性差と、花サイズ/花数の性差を別々に報告。花サイズ差のみで雄適応度の増大を推論しない。
- 性型比・雄型への距離・受粉成功の空間勾配を同時に測る。

## 主解析モデル（データ取得後）
1. 花サイズ: `log(flower_width) ~ sex + log(plant_size) + canopy_openness + DOY + (1|population) + (1|plant_id)` （同一株複数花なら）
2. 雌機能: `cbind(fruits, flowers-fruits) ~ sex * treatment + canopy_openness + (1|population/plant_id)`。ただし自家授粉は両性型にしかないので、全セル充足を仮定せず、**事前固定の識別可能な対比**を用いる。過分散に対してbeta-binomialも評価。
3. 自家和合性比: `SCI = P(fruit | hand_self, herm) / P(fruit | hand_outcross, herm)`。CIを付ける。自殖結実0/低率だけではSIの機構は確定しない。
4. 花粉制限: `PL = 1 - P(fruit|open) / P(fruit|open+supplement)`。両性型・雌型別、ゼロ分母に注意。
5. 昼夜: `fruit ~ exclusion_treatment + air_temp + bloom_date + (1|population/plant_id)`。
6. 空間: `fruit ~ nearest_herm_distance + local_herm_flower_density + canopy + DOY + (1|population)`。距離は位置同定精度と検出漏れを評価。

## プレ登録で避けたい落とし穴
- 低結実を「近交弱勢」や「自家不和合性」と同義にしない。
- 近縁ナニワズからオニシバリへ数値をコピーしない。
- 「雄個体が大型」は野外で株サイズの性差を測るまで使わない。
- 「送粉者がいない」は未観察と不在を区別。夜間と早朝の観察努力を明記。
- 植物体サイズ、花数、訪花数、花粉親成功度の因果順序を混同しない。
- 未熟果実を食害/落果/未受精で区別し、果実の誤食防止（有毒植物）を徹底。
- 花粉の標識、人工授粉、個体の採取には現地許可・管理ルールを遵守。

## 研究を先に進めるための判定順
**Gate 1: 性型** -- 真正の両性型と雌型があるか？
→ **Gate 2: 雌機能** -- 他殖人工授粉後に両性型は結実するか？
→ **Gate 3: 受精障害の段階** -- 自家/他家花粉管と胚のどこで失敗？
→ **Gate 4: 多チャネル送粉** -- 昼夜の結実、父性を確認。
→ **Gate 5: 雄花大型化の選択** -- サイズの効果を資源・花数・環境から分離。

**最初のデータが無い段階では仮説生成のみ。実証的な肯定結果を報告しない。**
